# ShaderArchive

Old Unity shaders kept for reference, not maintained.

- `3CharacterShaders/` toon character shader with its editor and textures
- `CGIncludes/` shared lighting, shadow, eye and AudioLink includes
- `Shader/` the `3NewShader` family (back-then-front and hair variants)
- `Misc/` AudioLink NaN marching, GPU particles, tension map, un-stereoed rendering, HMD detection

Copy whatever you need into `Assets/`.
